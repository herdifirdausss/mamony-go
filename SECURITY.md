# Security policy

Mamony Go is a synthetic simulator. Report security issues in this repository using synthetic data and disposable environments. See the [project status](docs/current-state.md) for the supported scope.

## Report a vulnerability privately

Sign in to GitHub, open the [Security Advisories page](https://github.com/herdifirdausss/mamony-go/security/advisories), and choose **Report a vulnerability**. Keep report details in the private advisory thread. Use public issues for ordinary bugs.

Include the affected commit or tag if known, the affected capability, the conditions needed to observe the issue, and its impact. Share only sanitized evidence. Exclude credentials, tokens, personal data, real transaction data, and access details for other systems.

Use the advisory thread to coordinate follow-up and disclosure with the maintainer.
